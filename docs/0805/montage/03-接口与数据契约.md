# 接口与数据契约

> 状态：部分实施
>
> 日期：2026-08-05

## 1. 契约原则

- MCP、REST 和 CLI 共享一个 OpenMontage application service。
- 视频任务必须异步，不让单次 MCP 调用等待完整渲染。
- 输入使用受控 URL 或 Artifact ID，不接受任意宿主机绝对路径。
- 输出返回 Artifact 元数据，不返回 MP4 base64。
- 外部接口使用版本化 schema、稳定错误码和幂等键。
- 新增字段优先保持可选和向后兼容。
- 第三方模型响应、下载内容和媒体 metadata 均视为不可信输入并在边界校验。
- 所有用户可感知 Job 状态变化必须先持久化为有序事件，再异步投影到聊天页；SSE 只负责失效通知，不作为事实来源。

## 2. OpenMontage REST API

```text
POST   /api/v1/jobs
GET    /api/v1/jobs/:jobId
POST   /api/v1/jobs/:jobId/cancel
POST   /api/v1/jobs/:jobId/approve
GET    /api/v1/jobs/:jobId/artifacts
GET    /api/v1/jobs/:jobId/usage
GET    /api/v1/jobs/:jobId/events?afterSequence=:sequence
GET    /api/v1/capabilities
GET    /healthz
```

REST 主要供 OpenMontage CLI、运维探针和 AgentSpace 服务端适配器使用。Agent 不直接获得 REST endpoint。

## 3. MCP 工具

首期公开：

| 工具 | 风险 | 说明 |
| --- | --- | --- |
| `openmontage_capabilities` | 低 | 返回当前镜像的视频、模型和 Artifact 能力 |
| `submit_video_job` | 高 | 创建有成本和资源影响的视频 Job |
| `get_video_job` | 低 | 查询状态、阶段和真实进度 |
| `cancel_video_job` | 中 | 取消 Job 和未开始的下游调用 |
| `approve_video_stage` | 高 | 通过 Pipeline 人工审批点或扩展预算 |
| `list_video_job_events` | 低 | 按 sequence 游标重放有序 Job 事件 |

`list_video_artifacts` 延后到 Artifact Bridge 落地后公开，避免在产物尚未进入 AgentSpace 授权和回收边界前暴露不可用的文件引用。

现有 `prepare_reference_clone` 和 `reference_clone_status` 可以保留为兼容工具，内部逐步改为调用同一 Job Service。

不要首期公开 `execute_tool(toolName, arbitraryInputs)`。OpenMontage 内部工具 registry 变化频繁，直接公开会绕过 workflow schema、审批和权限边界。

## 4. Job 创建契约

```json
{
  "schemaVersion": 1,
  "clientRequestId": "stable-idempotency-key",
  "workflow": "reference_clone",
  "input": {
    "type": "artifact",
    "artifactId": "artifact-id"
  },
  "brief": {
    "title": "产品介绍",
    "creativeDirection": "简洁、专业",
    "targetChannel": "short-video",
    "aspectRatio": "9:16",
    "durationSeconds": 30,
    "language": "zh-CN"
  },
  "output": {
    "container": "mp4",
    "videoCodec": "h264",
    "resolution": "1080x1920"
  },
  "budget": {
    "maxAmount": "20.00",
    "currency": "CNY"
  }
}
```

`workflow` 首期使用受控枚举：

- `reference_clone`
- `transcode`
- `compose`
- `caption_burn`
- `clip_factory`

输入 discriminated union：

```text
artifact: artifactId
url: sourceUrl
text: inlineText（仅适用于脚本/brief，不适用于二进制）
```

URL 必须经过协议、域名、重定向、DNS 和下载大小策略。服务不得读取工具参数中的本地绝对路径。

## 5. Job 响应

```json
{
  "schemaVersion": 1,
  "jobId": "job-id",
  "status": "RUNNING",
  "stage": "ASSETS",
  "progress": {
    "completedUnits": 2,
    "totalUnits": 5,
    "label": "Generating scene assets"
  },
  "budget": {
    "estimatedAmount": "12.40",
    "actualAmount": null,
    "currency": "CNY",
    "isAuthoritative": false
  },
  "artifacts": [],
  "error": null,
  "createdAt": "...",
  "updatedAt": "..."
}
```

状态：

```text
QUEUED
RUNNING
WAITING_APPROVAL
SUCCEEDED
FAILED
CANCEL_REQUESTED
CANCELLED
```

不得生成缺乏事实基础的百分比。若阶段无法提供细粒度进度，只返回阶段名和已完成/总步骤。

## 6. Artifact 契约

```json
{
  "artifactId": "artifact-id",
  "role": "final_video",
  "fileName": "final.mp4",
  "mediaType": "video/mp4",
  "sizeBytes": 12345678,
  "sha256": "64-hex",
  "durationSeconds": 30.04,
  "width": 1080,
  "height": 1920,
  "createdAt": "..."
}
```

MCP 只返回此元数据。上传、下载和回收通过 Artifact Bridge 完成，URL 必须短期有效且绑定 workspace、Job、操作和对象。

## 7. Usage Link 契约

OpenMontage 不返回自行计算的实际模型费用，只返回 models correlation：

```json
{
  "jobId": "job-id",
  "stage": "ASSETS",
  "operation": "IMAGE_GENERATION",
  "modelAlias": "model-alias",
  "gatewayRequestId": "request-id",
  "gatewayUsageId": "usage-id",
  "startedAt": "...",
  "endedAt": "..."
}
```

AgentSpace 使用 `gatewayUsageId` 从 models 对账并补充实际金额、币种和结算状态。

## 8. 错误契约

所有 REST 错误统一为：

```json
{
  "error": {
    "code": "OPENMONTAGE_BUDGET_EXHAUSTED",
    "message": "The delegated model budget has been exhausted.",
    "retryable": false,
    "details": {
      "jobId": "job-id",
      "stage": "ASSETS"
    }
  }
}
```

首期稳定错误码：

- `OPENMONTAGE_VALIDATION_FAILED`
- `OPENMONTAGE_ARTIFACT_NOT_FOUND`
- `OPENMONTAGE_ARTIFACT_DENIED`
- `OPENMONTAGE_CAPABILITY_UNAVAILABLE`
- `OPENMONTAGE_APPROVAL_REQUIRED`
- `OPENMONTAGE_BUDGET_EXHAUSTED`
- `OPENMONTAGE_DELEGATION_EXPIRED`
- `OPENMONTAGE_JOB_NOT_FOUND`
- `OPENMONTAGE_JOB_CONFLICT`
- `OPENMONTAGE_MODEL_UPSTREAM_FAILED`
- `OPENMONTAGE_RENDER_FAILED`
- `OPENMONTAGE_CANCELLED`

错误 message 可调整，调用方只能依赖 `code`、HTTP/MCP error category 和结构化字段。

## 9. 持久化边界

### AgentSpace

建议新增或扩展：

- `openmontage_service_bindings`
- `openmontage_job_links`
- `openmontage_usage_links`
- `runtime_credential_delegation_refs`

只保存 delegation ID、fingerprint 和状态，不保存明文 secret。

### OpenMontage

建议持久化：

- Job request snapshot
- Job state and stage checkpoints
- Approval decisions
- Artifact manifests
- models request/usage correlation
- local compute usage

### models

建议新增：

- Runtime credential delegation aggregate
- delegation lifecycle audit
- usage attribution 的 `sourceService/sourceInvocationId/externalJobId/stage`
- Billing Report 的 source service 和 external Job breakdown

这些字段应为显式受控 schema，不放进任意自由 metadata 作为授权或账务依据。

## 10. Job 事件契约

OpenMontage 需要提供事务 outbox，并向 AgentSpace 内部事件入口推送与 Job 状态同事务提交的事件。事件 envelope、顺序、重放、聊天投影和恢复规则以 [AI 员工聊天阶段可视化方案](./05-AI员工聊天阶段可视化方案.md) 为准。

硬性要求：

- `eventId` 全局唯一，`jobId + sequence` 唯一且 sequence 单调递增。
- 阶段状态变更和对应 outbox 事件必须原子提交，禁止“状态已变但事件丢失”。
- AgentSpace 接收端至少一次投递、幂等消费；发现序号缺口必须暂停投影并主动补偿。
- 每个事件携带可信 `workspaceId`、`employeeId`、`conversationId`、`rootTaskId` 和 `jobId` 关联，但不携带任何 delegation secret。
- `stage.progress` 只能使用事实步骤数；没有可验证总量时不得伪造百分比。

## 11. CLI 契约

```text
openmontage-client capabilities --json
openmontage-client job submit --request request.json --json
openmontage-client job status <job-id> --json
openmontage-client job cancel <job-id> --json
openmontage-client job approve <job-id> --stage <stage> --json
openmontage-client job artifacts <job-id> --json
openmontage-client job usage <job-id> --json
```

CLI stdout 在 `--json` 模式只输出单个 JSON 文档；诊断写 stderr；退出码保持稳定。CLI 不接受任意 shell 片段，不把 delegation secret 写入 argv、历史记录或配置文件。
