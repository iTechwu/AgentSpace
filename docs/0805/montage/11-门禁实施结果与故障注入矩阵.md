## 故障注入覆盖

当前代码级故障注入已覆盖：

1. 模型请求发送后 Worker 崩溃：invocation 标记 `unknown`，重启按同一 request key 复用 `modelInvocationId`。
2. 同一请求重放：SQLite 唯一键和 models delegation invocation 唯一键阻止重复预算与重复结算。
3. Job 取消：已有 Worker 的 cancel-requested 终态测试；MCP `cancel_running_jobs` 复用同一 Job action API。
4. Runtime/MCP 删除：运行中 Job、未 finalized delegation、未对账 token usage 均阻止最终 purge。
5. models 远端已成功但本地尚未收到响应：本地 invocation 不会被标记为可释放，后续 reconciliation 仍可按 delegation/Job 恢复。

生产开放前仍必须在真实部署环境执行以下跨容器 E2E，并保存 commit SHA、镜像 digest、迁移版本和账单查询结果：

| 场景 | 必须断言 |
| --- | --- |
| models 成功后立即 kill Worker | models usage、charge、ledger 各一条；聊天 Job 归因不丢 |
| 运行中删除 MCP（两种策略） | 新 Job 全部拒绝；取消策略的在途 Job 进入终态；历史账单可查 |
| 删除 Runtime / revoke delegation | 不继续产生新模型消费；reserved amount 释放或结算；最终 purge 只能在 guard 放行后发生 |
| 异步视频生成中取消 | OpenMontage、AgentSpace、models 三方状态一致；只结算实际消费 |
| 重放相同 invocation/event | exactly-once usage/charge/ledger，事件投影不重复 |
| 双员工并发与长视频 MP4 回收 | 员工归因隔离；最终 MP4 Artifact 可回收且账单不重复 |

这些部署级测试需要已重建的 OpenMontage 镜像、优惠豚 managed-node、models 内网地址/令牌和真实运行中的 AgentSpace；本工作站未执行 Jenkins 或生产部署。
