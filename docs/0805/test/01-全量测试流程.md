# AgentSpace 全量测试流程（0805）

> 测试基线：2026-08-05
>
> 测试视角：测试管理员账号 `13800138000`。密码仅在登录页面手工输入，不写入文档、截图、录屏、日志、HAR 或缺陷单。
>
> 目标环境：非生产测试环境；本地工作不启动或触发 Jenkins，不执行部署。

## 1. 测试目标与准出对象

本轮从真实用户进入 AgentSpace 开始，验证工作区内从消息到任务、数字员工、Runtime、Skill/MCP、审批、产物和治理数据的完整闭环，同时覆盖所有工作区模块、权限边界、异常恢复和移动端体验。

准出对象包括：

1. 登录和工作区隔离可靠，用户只看到当前身份与工作区允许的资源。
2. 17 个工作区模块可进入、可刷新、可前进后退，路由和选中状态一致。
3. 消息、频道、联系人、任务和 AI 员工可以完成可追溯的协作闭环。
4. Runtime 与模型选择正确；CLI/MCP/Skill 安装资格、授权、状态、调用和审计一致。
5. 知识、文档、表格、模板、自动化、日历、组织、费用、绩效、设置和审计数据正确落盘。
6. 越权、Secret 泄露、重复执行、失败重试、离线、刷新恢复和跨 Runtime 串扰均被阻断或可恢复。

## 2. 测试边界与安全约束

### 2.1 包含范围

- Web UI、Next 路由/API、服务层、PostgreSQL 测试数据和审计。
- SSO、模型服务、Daemon/Runtime、MCP egress、Skill Runner、飞书（若测试环境已配置）。
- Chrome/Chromium 桌面端、移动视口、键盘可操作性、英文界面、慢网和刷新恢复。
- 现有 Vitest、Node test、Playwright E2E，以及人工浏览器验收。

### 2.2 明确不做

- 不连接生产数据库、生产模型、真实客户群或真实计费资源。
- 不在 Docker Compose 中新增 PostgreSQL、Redis、RabbitMQ 服务。
- 不启动本地 Jenkins、不触发任何 Jenkins 构建或部署。
- 不把测试密码、Provider Token、MCP Secret、Cookie、session token 写入普通字段或证据。

### 2.3 暂停条件

发现跨工作区数据可见、Secret 回显、错误 Runtime 执行、重复计费/重复部署、不可逆删除或测试数据库疑似指向生产时，立即停止写操作，保留脱敏证据并通知负责人。

## 5. 执行顺序

严格按“先读后写、先基础后依赖、先 P0 后 P1”执行：

`环境基线 -> 登录/工作区 -> Shell/导航 -> 协作 -> 任务/员工 -> Runtime/能力 -> 内容/业务 -> 治理/安全 -> 非功能/恢复 -> 回归/清理 -> 准出`

## 6. 分阶段测试步骤

### 阶段 A：登录、会话与工作区隔离（AUTH/WS）

1. 无登录态打开首页，确认仅展示 SSO 登录入口；错误密码、取消登录、回调失败和会话过期均有可理解提示。
2. 使用测试账号登录，记录身份显示名、工作区列表、当前角色和默认工作区。
3. 复制工作区深链到新标签页，刷新、前进后退、退出后重新访问，确认认证和工作区上下文正确恢复。
4. 切换工作区（若账号可访问多个），比较 URL、侧栏、计数、消息、任务和搜索结果；旧工作区资源不得继续可见。
5. 使用不属于当前工作区的资源 ID、附件 URL、频道深链进行访问，UI 与 API 均拒绝且不泄露资源存在性。

### 阶段 B：工作区 Shell、导航与可用性（NAV）

1. 逐一打开第 4 节 17 个模块，验证标题、空态/有数据态、加载失败态和返回路径。
2. 在消息、任务、员工、知识、设置等带查询参数的页面切换筛选/子视图，刷新后查询参数、选中态和内容一致。
3. 快速连续切换模块、浏览器前进后退、折叠/展开侧栏，检查不出现重复布局、白屏、旧模块残留或 URL 漂移。
4. 使用全局搜索检索消息、任务、知识、文档和特殊字符，验证无结果、权限过滤、跳转来源和键盘 Escape 关闭。
5. 切换中文/英文，检查按钮、日期、状态和错误文案；在 `390 x 844` 视口验证侧栏抽屉、滚动、无水平溢出。

### 阶段 C：消息、频道、联系人与附件（COL/CHAT）

1. 创建普通频道，添加人类成员和 AI 员工；验证重复名称、空名称、成员不存在和无权限时的错误。
2. 发送文本、长文本、提及、连续重复消息、附件和空消息；检查输入框清空、发送中/成功/失败状态、未读计数和刷新持久化。
3. 从人类联系人和数字联系人分别发起私聊；切换 `all/direct` 视图和 focus 参数，确认选中会话保持。
4. 从消息进入任务或员工执行，返回原会话确认上下文、消息关联和产物链接。
5. 下载附件、访问过期/不存在附件、跨工作区附件 URL，检查权限、错误提示和日志脱敏。
6. 使用频道文档编辑、保存、回滚、导出和冲突处理（按当前角色验证只读/可写边界）。

### 阶段 D：任务、审批与 AI 员工（TASK/EMP/APP）

1. 创建任务，填写标题、描述、负责人、优先级、截止时间和频道；检查必填、重复提交和取消。
2. 在任务看板拖动或菜单切换 `todo/in_progress/completed/failed/cancelled`，刷新后状态、计数和时间线一致。
3. 创建/编辑 AI 员工，验证基本信息、说明、Owner、频道成员关系、Runtime、模型和 Skill 绑定。
4. 对离线 Runtime、未配置模型、未就绪 Skill、禁用 MCP 的员工发起任务，系统必须在执行前阻断并给出恢复动作。
5. 发送同一份任务给两名不同 Runtime 的员工，确认 `queued -> running -> completed/failed` 合法流转、只产生一条任务、消息和产物可追溯。
6. 触发需要审批的动作，分别测试待审批、通过、拒绝、过期、重复处理、审批后继续和取消任务。
7. 停止运行中的任务、重试失败任务、刷新任务详情和重新登录，确认不会误标 completed、不会重复扣费、历史证据不被覆盖。

### 阶段 E：Runtime、模型与托管节点（RUN）

1. 检查 Runtime 列表、详情、Provider、协议、模型目录、默认模型、节点、最后心跳、共享策略和凭据遮罩。
2. 管理员创建 Codex/Claude（或环境实际支持的 Provider）Runtime：完成预检、名称、节点、独立/共享策略、模型选择、提交、部署和心跳验证。
3. 验证模型过滤：只允许与 Provider 协议兼容的模型；余额不足、模型不可用、节点离线时不创建资源。
4. 重复点击创建、刷新中断、失败重试、取消部署和删除有引用 Runtime，检查幂等、状态机和删除保护。
5. 停用/恢复 Runtime，观察员工可用性、排队任务、错误诊断和恢复后重试；两个 Runtime 的状态与凭据不得串用。

### 阶段 F：CLI 市场、MCP 连接与 Skill（CAP）

#### F1. 市场基线

1. 进入 `/market`，检查 CLI/MCP 分类、来源标签（平台官方、CLI-Anything 工具套件、社区目录、Skill 依赖）、目录条目数、最后同步时间和陈旧状态。
2. 检查筛选后列表与详情一致；无结果、来源失败、陈旧目录和条目详情错误均有可恢复提示。

#### F2. CLI 安装资格与生命周期

对每个目标 Runtime 分别执行：

1. 选择低风险、精确版本、明确入口的目录项，记录 source、slug、version、entrypoint、安装策略和所需工具。
2. 验证 `installable / needs_configuration / unsupported` 展示与服务端判断一致；Runtime 缺少 npm/Python/pip/CLI-Hub 时显示原因并禁用主动作。
3. 使用安装计划预检，确认目标 Runtime、受控 argv、验证命令、风险和审批项；重复点击只产生一个 operation。
4. 对 `latest`、范围版本、无 artifact digest/commit、缺入口、缺安装声明、`curl | bash`、重定向、命令替换、`sudo` 等条目，确认前端禁用且服务端硬阻断。
5. 正常安装后执行 `--version`/只读探针，检查 `installed/enabled`、operation、Runtime 私有 HOME、审计和来源事实。
6. 验证更新失败保留旧版本、停用后新任务不可用、卸载后历史任务快照不变；Codex 与 Claude 的安装记录、状态和命令互不覆盖。

#### F3. MCP 连接与工具授权

1. 选择已批准的低风险只读 MCP，核对 transport、release、endpoint/allowed hosts、声明工具和数据域。
2. 先检查 Runtime 依赖，再配置连接；Secret 只通过凭据中心录入，页面、URL、日志和截图不得回显。
3. 仅批准任务必需工具；未批准工具必须进入审批或被拒绝，不能静默执行。
4. 连接达到 `ready` 后执行重新验证，检查 last verified、next check、连续失败数和审计字段。
5. 修改非敏感配置时空 Secret 表示保留原值；错误 endpoint、网络超时、凭据错误给出稳定错误码和可恢复动作。
6. 停用/恢复连接，验证新任务门禁、历史任务快照、跨 Runtime 隔离和重复提交幂等。

#### F4. Skill 生命周期

1. 创建或导入 `QA-0805-Capability-Probe-<HHmm>`，检查 `SKILL.md`、文件清单、输入输出、禁止事项和 CLI/MCP 能力声明。
2. 发布并记录版本、digest、来源和风险；同一版本重复发布/安装不产生重复 operation。
3. 分别安装到两个 Runtime，完成依赖检查、逐项授权、就绪确认；缺少必需能力时禁止显示 ready。
4. 在任务中调用 Skill，核对 installation/digest/entrypoint、CLI/MCP 调用、结果和审计；不允许任意 shell、越权网络或外部写入。
5. 升级、回滚、解绑和卸载后重跑任务，验证新旧快照、历史任务和另一 Runtime 不受影响。

### 阶段 G：知识、文档、表格、模板与业务工具（DATA）

1. 创建/编辑知识页和文档，执行搜索、权限申请、并发修改、冲突、版本、回滚和导出；验证频道文档与消息关联。
2. 创建表格、添加/编辑/删除记录、刷新和移动端查看，验证字段校验、空态、长文本和权限。
3. 从模板创建对象，修改模板后确认已创建对象不被反向污染；验证模板权限和删除保护。
4. 创建自动化/日历事件，检查时区、启停、触发一次性、失败记录、重复执行保护和取消。
5. 验证组织架构成员、层级、Owner 和权限继承；撤销成员后 UI/API/附件/频道访问同时失效。

### 阶段 H：设置、集成、费用、绩效与审计（GOV）

1. 在设置中验证账户、偏好、语言、主题/侧栏、通知、安全会话、权限和集成入口；敏感值只显示已配置状态。
2. 若纳入飞书，执行连接/回调校验、用户绑定、机器人/频道绑定、健康和凭据轮换；失败不影响工作区其他模块。
3. 核对成本按工作区、员工、Runtime、模型和任务维度聚合，时间范围切换和刷新不产生重复记录。
4. 核对绩效与任务完成、响应时间、失败率和员工维度一致；空数据和权限不足有明确空态。
5. 在审计页检索本轮资源，确认 actor、workspace、object、action、outcome、request/task/operation 关联和时间；Secret、Token、Cookie 不出现。
6. 对 Member/Admin/Owner 角色执行入口隐藏、深链拒绝、Server Action/API 拒绝和审计记录检查。

### 阶段 I：非功能、兼容与恢复（NFR）

1. Chrome/Chromium `1440 x 900` 完成所有 P0；移动 `390 x 844` 完成登录、消息、任务、Skill、审批、员工和导航 P0。
2. 补充 Edge/Safari（可用时）、英文界面、键盘导航、焦点、弹窗 Escape、表单错误播报和读屏标签。
3. 模拟 Fast 3G、请求超时、断网后恢复、后台标签页、快速重复点击和多标签页编辑；检查重试、去重和草稿恢复。
4. 记录首屏、模块切换、消息发送、搜索、任务提交和详情加载的 P50/P95；超过产品目标则登记性能缺陷。
5. 在指定测试环境执行数据库备份/恢复、员工工作区恢复、Runtime/任务恢复和产物恢复；验证恢复后 ID、版本、审计和权限不变。

## 7. 证据、缺陷与清理

### 7.1 证据要求

每个 P0/P1 用例至少记录：用例 ID、环境/commit、角色/工作区、时间、前置数据、操作摘要、预期/实际结果、状态、截图或短录屏、request ID、脱敏响应和清理状态。资源 ID 可记录，Secret 仅记录 `configured=true` 或脱敏指纹。

### 7.2 缺陷分级

| 等级 | 判定 | 处理 |
| --- | --- | --- |
| S0 | 越权、敏感信息泄露、不可逆破坏、跨工作区污染 | 立即停写，阻断准出 |
| S1 | 登录、消息、任务、Runtime 主链路中断或结果丢失 | 阻断发布，优先修复 |
| S2 | 主要功能受损但有绕行，统计/状态明显错误 | 必须有版本或书面风险接受 |
| S3 | 文案、低频展示或轻微兼容问题 | 纳入后续回归 |

### 7.3 清理顺序

1. 等待本轮任务、安装和连接 operation 均结束，无 `running/queued` 残留。
