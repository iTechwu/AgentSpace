# AgentSpace 全量测试执行报告（2026-08-05）

## 1. 测试结论

本轮按 `docs/0805/test` 测试用例，以管理员用户视角在正确地址 `https://agentspace.local.dofe.ai` 完成浏览器回归、业务数据闭环、Runtime/CLI/MCP/Skill 检查、移动端适配检查及自动化回归。

结论为 **有条件通过，暂不满足完整端到端准出条件**：

- 登录、工作区切换、17 个桌面模块、9 个移动端核心页面、知识/数据表/自动化/日历/模板数据闭环均通过。

- 测试发现的 AgentSpace 业务代码问题已修复并回归通过。
- 唯一未闭环项为模型实际生成：任务能够被在线节点领取并进入“思考中”，但 `deepseek-v4-flash` 推理长时间无响应。AgentSpace 控制面、Runtime 网络、TLS 和模型健康接口均正常，阻塞位于外部模型推理/模型配置链路。本机未修改 `models.dofe.ai`，也未执行部署。

## 6. 模型推理阻塞分析

使用两条最小任务提示词验证任务执行，其中一条明确要求“仅回复 OK，不调用工具，不访问外部网络”。两条任务均完成以下步骤：

1. AgentSpace 接收任务并写入队列。
2. 在线 managed node 领取任务。
3. Runtime 启动并进入“思考中”。
4. 全程没有工具调用或审批请求。
5. 等待两分钟以上仍无模型输出；从 UI 停止后，任务和 attempt 均正确落为 `cancelled`，且无残留任务容器。

进一步只读验证结果：

- `https://model.local.dofe.ai/api/health` 从宿主访问返回 200。
- 使用与动态 Runtime 相同的镜像、Docker 网络、host-gateway 和 CA 挂载访问健康接口，同样返回 200。
- `dofe-models-web-local`、`dofe-models-api-local` 和 managed node 健康状态正常。

据此可排除 AgentSpace 队列、节点领取、Runtime 基础网络、DNS 和 TLS 配置问题。剩余阻塞集中在 `deepseek-v4-flash` 的实际推理或上游模型配置，属于相邻模型系统范围；在该链路恢复前，消息最终回复、Skill 在任务中的真实调用、审批后继续执行和产物回写无法完成端到端验收。
