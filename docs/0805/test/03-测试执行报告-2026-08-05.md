## 5. 发现与修复

### FIX-001：`pnpm dev:web` 无法启动

- 现象：Next.js 将 `--hostname` 误识别为项目目录，启动失败。
- 原因：根脚本向 pnpm 子脚本多传了一个 `--`。
- 修复：调整根 `dev:web` 参数透传方式。
- 回归：Next.js 16.2.12 成功监听 `0.0.0.0:1455` 并进入 Ready。

### FIX-002：外部字体请求导致控制台网络错误

- 现象：Google Fonts 请求在当前网络中 `ERR_CONNECTION_RESET`。
- 原因：全局 CSS 依赖运行时外部字体；页面实际字体变量已有系统字体回退。
- 修复：移除 Google Fonts `@import`，保留系统字体栈。
- 回归：首页刷新后该失败请求和对应控制台错误消失，布局与文本正常。

### 非缺陷确认：离线 Runtime 下消息草稿清空

真实请求返回 200，消息已持久化并显示为排队等待节点，不属于提交失败。输入框清空符合“服务端已受理”的现有交互；提交抛错时恢复草稿的组件测试通过。

### 9.3 新增缺陷与修复

#### FIX-003：数据表单元格无法稳定编辑

- 现象：新增行后单元格存在于 DOM，但真实 Chrome 无法完成输入；操作等待持续超时。
- 根因：受控输入在每次 `onChange` 时立即调用 Server Action 并刷新模块，输入节点在键入过程中反复被替换。
- 修复：单元格使用本地草稿，仅在失焦或 Enter 时提交；同时增加列名可访问标签。
- 回归：输入期间 0 个写请求；失焦后恰好 1 个 POST、状态 200；刷新后值持久化；测试表已删除。
- 提交：`45e8fa4`。

#### FIX-004：移动端隐藏侧栏仍进入键盘焦点和可访问性树

- 现象：侧栏视觉上已移出屏幕，但 Tab 会先遍历关闭按钮、全部导航链接和退出登录；可访问性树仍暴露整个侧栏。
- 根因：关闭状态只使用 `transform`、`opacity` 和 `pointer-events`，没有改变可访问性可见性。
- 修复：移动侧栏和遮罩关闭时使用 `visibility: hidden`，打开时恢复，并保留过渡；移动 E2E 增加关闭/打开可见性断言。
- 回归：关闭时侧栏不在可访问性树、不进入 Tab 顺序；打开后恢复、可关闭；无溢出和 console error。
- 提交：`0dabd57`。
