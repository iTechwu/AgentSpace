## 1. 与文档 API 模型的调和（重要决策）

[02-架构设计 §7](./02-架构设计.md) 列出的是一套 `/api/skills/*` REST。但本仓库现状是：**skill 管理走 Next.js Server Actions，执行面走 `/api/daemon/...` REST**。为保持一致性，做如下映射，**不新增 `/api/skills/*` 域**：

| 文档 API（逻辑） | 实际落点 | 类型 |
| --- | --- | --- |
| `POST /api/skills/resolve-source` | `apps/web/features/skills/actions.ts` → `resolveSkillSourceAction` | Server Action |
| `POST /api/skills/artifacts` | `createSkillArtifactAction` | Server Action |
| `GET /api/skills/artifacts/:digest/inspection` | `inspectSkillArtifactAction` | Server Action |
| `POST /api/skill-installations` (+retry/activate/rollback/delete) | `apps/web/features/skills/installation-actions.ts`（新） | Server Action |
| `POST /api/skill-service-bindings`、`/api/managed-skill-services/*` | `apps/web/features/skills/service-actions.ts`（新） | Server Action |
| `GET /api/daemon/runtimes/:runtimeId/skill-operations/claim` | `apps/web/app/api/daemon/runtimes/[runtimeId]/skill-operations/claim/route.ts`（新） | REST（daemon） |
| `POST /api/daemon/skill-operations/:id/{start,complete,fail}` | `apps/web/app/api/daemon/skill-operations/[operationId]/{start,complete,fail}/route.ts`（新） | REST（daemon） |

理由：与现有 `runtimes/[runtimeId]/mcp-operations/claim`、`runtime-app-operations/[id]/start|complete|fail` 完全对称；daemon 操作面是机器对机器，必须 REST；管理面是人机交互，Server Action 与现状一致且避免重复鉴权层。

## 2. 数据模型（全阶段共用）

新增表，DDL 写入 [packages/db/src/postgres-schema.ts](../../packages/db/src/postgres-schema.ts) 表注册数组（`:42-47`）与定义区（接 `agent_skill_requirement_config` 之后，约 `:1031` 处），索引追加到 `:2039-2056` 的 skill 索引区。风格严格对齐 `mcp_*` 表（`TIMESTAMPTZ`/`JSONB`/`REFERENCES ... ON DELETE CASCADE`/`UNIQUE`/`TEXT` 主键）。

### 2.1 `skill_artifact`（不可变包）

```sql
CREATE TABLE IF NOT EXISTS skill_artifact (
  digest TEXT PRIMARY KEY,                       -- sha256:<hex>，canonical
  workspace_id TEXT NOT NULL REFERENCES workspace(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  version TEXT NOT NULL DEFAULT '',
  description TEXT NOT NULL DEFAULT '',
  manifest_json JSONB NOT NULL,                  -- .dofe/manifest.json 全文
  schema_version INTEGER NOT NULL DEFAULT 1,
  source_type TEXT NOT NULL,                     -- github|skills.sh|clawhub|local|tos|manual|runtime|catalog
  source_url TEXT,
  resolved_ref TEXT,                             -- 锁定的 commit SHA / registry digest
  original_url TEXT,                             -- 用户原始输入（mutable）
  risk TEXT NOT NULL DEFAULT 'unknown',          -- unknown|low|medium|high
  scan_version TEXT NOT NULL DEFAULT '',
  file_count INTEGER NOT NULL DEFAULT 0,
  total_size_bytes BIGINT NOT NULL DEFAULT 0,
  created_by_user_id TEXT REFERENCES users(id) ON DELETE SET NULL,
  created_at TIMESTAMPTZ NOT NULL,
  UNIQUE(workspace_id, digest)
);
```

### 2.2 `skill_artifact_file`（文件清单 + blob 引用）

```sql
CREATE TABLE IF NOT EXISTS skill_artifact_file (
  digest TEXT NOT NULL REFERENCES skill_artifact(digest) ON DELETE CASCADE,
  path TEXT NOT NULL,
  sha256 TEXT NOT NULL,
  size_bytes BIGINT NOT NULL,
  media_type TEXT NOT NULL,
  mode TEXT NOT NULL DEFAULT '0644',             -- 保留可执行位
  is_binary BOOLEAN NOT NULL DEFAULT FALSE,
  text_content TEXT,                             -- 文本内联；二进制为 NULL，走 blob_ref
  blob_ref TEXT,                                 -- 复用 attachments 的 storedPath/storageKey
  PRIMARY KEY (digest, path)
);
```

### 2.3 `skill_installation`（artifact × runtime 的准备结果）

```sql
CREATE TABLE IF NOT EXISTS skill_installation (
  id TEXT PRIMARY KEY,
  workspace_id TEXT NOT NULL REFERENCES workspace(id) ON DELETE CASCADE,
  runtime_id TEXT NOT NULL REFERENCES agent_runtime(id) ON DELETE CASCADE,
  artifact_digest TEXT NOT NULL REFERENCES skill_artifact(digest) ON DELETE RESTRICT,
  status TEXT NOT NULL,                          -- inspecting|approval_required|preparing|blocked|ready|degraded|retired
  resolved_lock_json JSONB NOT NULL DEFAULT '{}'::jsonb,  -- SkillReleaseLock
  prepared_path TEXT,                            -- Runtime cache 抽象标识，非宿主绝对路径
  health TEXT NOT NULL DEFAULT 'unknown',
  previous_ready_revision TEXT,                  -- 回滚锚点
  revision TEXT NOT NULL,                        -- installation revision
  installed_at TIMESTAMPTZ,
  verified_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ NOT NULL,
  updated_at TIMESTAMPTZ NOT NULL,
  UNIQUE(workspace_id, runtime_id, artifact_digest, revision)
);
```

### 2.4 `skill_installation_component`（依赖/脚本/CLI/MCP/服务组件状态）

### 7.1 release lock 与 diff

- 服务有状态时按 `rollback_class`：`stateless` 蓝绿 / `backward_compatible` 扩展-部署-收缩 / `irreversible_migration` 禁自动回滚需运维变更单
- `agent_skill.rollout_pin` 固定已运行任务到创建时 revision；新任务 rollout 切换后用新 revision
