# Runtime 详情页展示名称与首屏优化设计

## 目标

优化托管 Runtime 详情页的首屏信息层级，并允许管理员修改 Runtime 的用户侧展示名称。底层 Runtime 标识、供应商名称和任务路由信息保持不变。

## 交互方案

- 在 Runtime 标题旁提供编辑入口，点击后原位切换为输入框。
- 输入框默认填充当前展示名称；按 Enter 保存，按 Escape 或点击取消恢复原值。
- 展示名称去除首尾空格后必须为 1 至 80 个字符。
- 保存期间禁用重复提交并展示进行中状态。
- 保存成功后立即刷新标题并给出成功反馈；保存失败时保留输入内容和错误提示。
- 编辑按钮、输入框和保存/取消操作均提供明确的无障碍名称和键盘焦点状态。

## 数据边界

- 使用现有 `updateWorkspaceRuntimeDisplayNameAction` 更新展示名称。
- 不修改底层 Runtime ID、运行凭据、供应商注册名称或任务分派关系。
- 页面保留底层 Runtime 标识作为辅助信息，便于运维排查。

## 视觉与布局

- 将标题、部署类型、状态和操作组织为紧凑的首屏信息区，减少无意义留白。
- 编辑入口贴近标题，使用现有图标与按钮体系，不引入新的视觉语言。
- 提升连接信息与容量费用区域的扫描效率：统一标题层级、字段间距和数字对齐。
- 桌面端保留双栏信息布局；窄屏下按标题、状态、操作、概览内容顺序纵向排列。
- 延续现有浅色绿色主题，仅调整对比度、间距和操作显著性。

## 验证范围

- 组件测试覆盖进入编辑、取消、校验失败、保存成功和保存失败。
- 页面测试确认展示名称组件获得正确的 Runtime 数据。
- 浏览器验证桌面和移动视口下无重叠、无横向溢出，并验证键盘操作与保存后的标题更新。
