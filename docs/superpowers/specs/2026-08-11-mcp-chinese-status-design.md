# MCP 页面中文状态展示设计

> 状态：✅ 已实施并合入主链（2026-08-17 复核确认）。实现见 `apps/web/features/market/capability-presentation.ts`（mcpTransportLabel 等）及 `mcp-presentation.test.ts`。计划勾选框未回填，以实际代码为准。

## 目标

将 MCP 相关页面中的英文枚举和下划线状态转换为稳定、易读的中文文案。保持现有后端状态值、连通性判断、轮询和操作流程不变。

## 范围

- MCP 市场目录：传输类型、风险等级、目录连接状态和 Runtime 数量说明。
- MCP 详情与已连接列表：连接状态、传输类型、操作按钮和验证时间说明。
- Runtime 能力面板：MCP 传输类型、连接状态和操作历史状态。
- MCP 连接详情页：传输类型、连接状态、验证阶段和操作状态。
- 保留环境变量名、stdio URI、endpoint 和工具名等技术标识符原文；只翻译其周边标签。

## 文案映射

| 原始值 | 中文展示 |
| --- | --- |
| `streamable_http` | 流式 HTTP |
| `managed_stdio` | 受管 stdio |
| `managed_service` | 受管服务 |
| `sse` | SSE |
| `low` | 低风险 |
| `medium` | 中风险 |
| `high` | 高风险 |
| `pending_configuration` | 待配置 |
| `queued_verification` | 等待验证 |
| `verifying` | 验证中 |
| `ready` | 已验证 |
| `degraded` | 连接异常 |
| `failed` | 验证失败 |
| `disabled` | 已停用 |

无法识别的未来枚举值使用“状态未知”或原值降级显示，不能导致页面渲染失败。

## 交互与可访问性

- 不改变现有按钮动作和禁用条件。
- 连接状态继续使用现有颜色语义：成功、进行中、异常/失败、停用。
- 状态文本同时用于可访问名称，不能只依赖颜色区分。
- 技术值保留在表单输入和工具名称中，避免中文化破坏复制和配置。

## 验证

- 为每个映射增加单元测试，确保 MCP 页面不渲染原始传输和状态枚举。
- 运行 MCP 市场、Runtime 能力和连接详情相关测试。
- 运行 Web 类型检查，确认映射类型覆盖现有枚举。

## 非目标

- 不增加保存前“测试连接”按钮。
- 不修改数据库状态枚举或 daemon 验证流程。
- 不修复本次之前发现的表单轮询导致工具勾选丢失问题。
