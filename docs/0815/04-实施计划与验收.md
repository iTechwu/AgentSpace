## 2. 数据模型变更（DDL）

新增 `skill_rollout_plan` 表（一次审批绑定依赖闭包 + 目标 Runtime 集合 + planDigest）：

```sql
CREATE TABLE skill_rollout_plan (
  id TEXT PRIMARY KEY,
  workspace_id TEXT NOT NULL REFERENCES workspace(id) ON DELETE CASCADE,
  root_artifact_digest TEXT NOT NULL,
  plan_digest TEXT NOT NULL,
  policy_version TEXT NOT NULL DEFAULT 'v1',
  closure_json JSONB NOT NULL,          -- 有序依赖闭包（coordinate + digest + placement）
  target_runtimes_json JSONB NOT NULL,  -- 目标 Runtime 集合
  risk_summary_json JSONB NOT NULL DEFAULT '[]'::jsonb,
  decision TEXT NOT NULL,               -- pending | approved | rejected
  actor_user_id TEXT REFERENCES users(id) ON DELETE SET NULL,
  created_at TIMESTAMPTZ NOT NULL,
  consumed_at TIMESTAMPTZ,
  UNIQUE(workspace_id, plan_digest)
);
```

`skill_installation` 增加 `rollout_plan_id` 外键（可空，单装时为空），并加索引：

```sql
ALTER TABLE skill_installation ADD COLUMN rollout_plan_id TEXT
  REFERENCES skill_rollout_plan(id) ON DELETE SET NULL;
CREATE INDEX idx_skill_installation_rollout_plan ON skill_installation(rollout_plan_id);
```

说明：planDigest 只对 `decision=approved` 且未超范围（子安装的 `artifactDigest` 属于 plan 声明的闭包、`runtimeId` 属于目标集合）时有效。

## 4. 验收清单

| ID | 验收项 | 通过标准 |
| --- | --- | --- |
| ACC-01 | 依赖闭包解析 | `planSkillRollout` 返回完整有序闭包，循环报 `skill_dependency_cycle` |
| ACC-02 | 版本锁定 | 版本范围解析为确切 artifact digest，planDigest 稳定可复算 |
| ACC-03 | 目标集合 | 三种 targetScope 正确映射 Runtime；`novel-production` 映射到协调者 Runtime |
| ACC-04 | 一次审批 | 5 个 Skill + 3 Runtime 只产生一个 `skill_rollout_plan`，子安装不重复审批 |
| ACC-05 | 原子幂等 | 并发批量安装不撞唯一键，重复执行返回已有记录 |
| ACC-06 | preflight 门禁 | 缺安装时 Workflow 不激活；必需目标全部 ready 后放行 |
| ACC-07 | 收敛 DAG | 两轮展开图通过 `validateWorkflowGraph`（无 cycle 错误） |
| ACC-08 | 256 KB 约束 | 节点 `outputJson` 不含大 JSON，产物经 artifact manifest 传递 |
| ACC-09 | 失败归因 | 缺资产错误能定位到镜/角色/场景，并回填到对应收敛轮 |
| ACC-10 | 可解释进度 | 编排入口一次操作展示“补齐 N 个 Skill、涉及 M 个 Runtime、X 项已就绪、Y 项待安装” |

## 5. 风险与边界

- **循环依赖**：planner 必须 fail-closed，拒绝任何循环，不允许静默截断闭包。
- **可选依赖**：`dependencyMode: "include-optional"` 是显式选择，默认 `required-only`；可选依赖缺失不阻断激活，但必须在 plan 里显式标记为 skipped。
- **审批越界**：子安装的 digest/runtime 必须严格属于 plan 声明的闭包与目标集合，防止一张批准覆盖未展示的风险。
- **Runtime 能力差异**：`all-compatible` 需按 Runtime 能力（有无 GPU/出网）过滤，不能对不兼容 Runtime 下发 shot-generation。
- **不回填执行中途安装**：任务执行中途禁止临时安装；缺项只能阻断并回到 preflight，保证可复现与可审计。
