## 范围基线

本方案依据当前代码中的实际路由、导航、服务和既有测试整理，主要范围如下：

1. Dofe SSO 登录、工作区同步、切换与退出。
2. 通知、审批、项目看板、消息、联系人和全局搜索。
3. 员工管理、数字员工展板、组织架构、模板和任务执行。
4. 执行引擎、远程 Runtime、模型选择、运行状态与产物。
5. 技能库、Skill 安装/导入、Runtime App 市场和 MCP 连接。
6. 知识库、文档、附件、数据表、自动化与定时任务。
7. 费用、预算、绩效、权限、集成、安全会话和审计日志。
8. 响应式布局、可访问性、性能、并发、异常恢复和数据一致性。

## 执行原则

- 先只读、后新增、再修改、最后删除，避免测试数据相互污染。
- 首次登录后先记录账号的工作区、角色和平台权限。界面可见性与服务端授权必须分别验证。
- 所有可写数据使用统一前缀 `QA-0803-`，执行结束后按清单回收。
- P0 主链路每个构建都执行；P1 在全量轮执行；P2 在发布候选版本执行。
- 任何密码、令牌、Cookie、MCP Secret、飞书密钥和附件签名 URL 都必须在证据中脱敏。
- 本工作站不使用 Jenkins。本方案只覆盖本地/测试环境验证，不包含部署操作。

## 交付物

每轮执行至少产生以下结果：

- 环境和构建信息记录。
- 用例结果表，状态限定为 `通过 / 失败 / 阻塞 / 不适用`。
- P0/P1 缺陷清单及复现证据。
- 测试数据创建与清理记录。
- 回归结果和最终准出结论。
