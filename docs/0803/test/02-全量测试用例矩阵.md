# 02. 全量测试用例矩阵

## 1. 使用说明

- 优先级：`P0` 为每次构建必测，`P1` 为全量轮必测，`P2` 为发布候选版本补充。
- 类型：`正向`、`异常`、`权限`、`恢复`、`兼容`。
- 结果只使用 `通过 / 失败 / 阻塞 / 不适用`，不得用“基本通过”。
- 标注“条件”的用例在当前环境具备对应角色或依赖时执行；不具备时必须完成权限拒绝或依赖缺失体验验证。

## 14. 测试结果汇总口径

| 指标 | 计算方式 |
| --- | --- |
| 执行率 | 已执行用例数 / 应执行用例数 |
| 通过率 | 通过数 /（通过 + 失败）|
| P0 通过率 | P0 通过数 / 已执行 P0 数 |
| 缺陷重开率 | 回归后重开缺陷数 / 已回归缺陷数 |
| 阻塞率 | 阻塞数 / 应执行用例数 |

“不适用”必须写明角色、模式或依赖原因；环境缺失导致无法判断产品结果时记为“阻塞”，不能记为“通过”。
