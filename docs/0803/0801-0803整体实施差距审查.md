### 3.1 `.env` 配置核验

- 当前真实 `.env` 未发现重复键，也没有遗留的 `MCP_EGRESS_PROXY_LEASE_SIGNING_SECRET` 共享 HMAC 配置；
- `MANAGED_RUNTIME_TLS_CA_PATH` 与 `MANAGED_RUNTIME_DOCKER_EXTRA_HOSTS` 是本地 Runtime 连通性配置，不是 Secret 泄漏，保留不动；
- 当前真实 `.env` 未启用 MCP egress proxy，因此没有强行写入私钥、公钥或 admin token 占位值；启用时必须按 `.env.example` 生成并挂载真实 Ed25519 key，不能使用示例值；
- `.env.example` 已新增 `DOFE_AGENT_SKILL_LOCAL_IMPORT_ROOTS=/srv/dofe-agent/skills`。真实 `.env` 未配置时，服务器目录导入会明确拒绝，不影响 Git/ZIP 等其他导入渠道；只有部署方确认允许目录后才应设置该绝对路径白名单。

## 5. P1：仍需实现或进一步优化

### P1-1：MCP proxy 的多副本语义

Ed25519 控制面私钥签名/proxy 公钥验签、算法降级拒绝、单机 JTI 重启持久化、policy/revoke 持久重放、指标和 admin token 轮换已经实现，不应再列为缺口。仍未完成的是：

- 当前 replay state 只保证单 proxy 实例重启语义；多副本仍需要共享、原子、带 TTL 的一次性消费；
- 对持久 policy/revoke feed 做崩溃恢复、多副本一致性、积压与延迟告警的长期演练；
- 把 request/reject/latency/revoke 指标接入实际告警、容量规划和灰度回滚，而不只停留在指标端点。

### P1-2：MCP 产品范围补齐

- `OAuthInjector` 仍明确是 Phase 3 占位实现，OAuth MCP 不能 GA；
- 受管 stdio MCP 尚缺独立服务容器、固定镜像 digest、私网 bridge、短期凭据和生命周期管理；
- 工作区私有 MCP 目录/私有服务审核和复用尚未形成完整产品入口；
- OpenCode、OpenClaw、Hermes 等 Provider adapter 尚未进入支持范围；
- Codex 虽已有实验开关，仍需要面向管理员的版本兼容诊断、隔离说明和失败证据。

### P1-3：Skill 产品入口已关闭，真实 canary 与可用性仍待

- Web 已提供受控服务器目录导入，服务端用绝对根白名单和 `realpath` 阻断路径/符号链接逃逸，并记录导入审计；
- 安装向导已提供“复用或创建”和“仅绑定已有健康服务”，严格模式验证 Runtime、catalog、健康状态与 `runtime-private://` endpoint，且不会为不可用可选服务偷偷创建实例；
- 控制面、错误信息和测试已统一称为 blue-green。真实 canary 仍需 rollout 资源、目标集合、观察窗、阈值和自动回滚；
- 安装页已提供管理员可下载的脱敏诊断 JSON，采用白名单结构和每次导出独立盐值 HMAC 引用；剩余是管理员可用性研究。

### P1-4：数据一致性边界、规模和节点磁盘效率

reconciliation 重复执行与跨节点竞争已有故障注入证明，但仍应逐个补齐跨系统退出边界：

- blob 上传成功后进程退出、artifact 发布后 revision CAS 冲突；
- revision committed 后 completion 响应丢失、重复回调和长时间网络分区；
- 真实 TOS/弱网下 20 GiB workspace Range 续传、并发上传、限流和恢复耗时；
- 持久 mount 的只读基线加可写 overlay，减少每次任务全量物化和节点磁盘放大；
- 节点磁盘水位、cache eviction 与活跃 snapshot/依赖环境之间的安全联动。

### P1-5：运营证据和产品质量闭环

legal hold 案件引用/导出、revision 长期保留与删除证明、pager 升级/恢复通知、SLO 看板均已实现。下一步需要把“代码存在”提升为持续运营证据：

- 在真实 pager 接收端演练去重、升级、恢复通知和超期告警；
- 验证 workspace head age、恢复时长、digest failure、binding conflict、容量和 RPO/RTO 告警阈值；
- 完成 legal hold 细粒度权限矩阵、审计抽查和恢复后治理规则复验；
- 对 Skill 安装完成率、耗时、状态理解率和误授权率做真实管理员研究。
