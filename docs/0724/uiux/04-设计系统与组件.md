# 04. 设计系统与组件

## 视觉方向

风格定位为“可靠的运营控制台”：白色内容面、非常浅的冷灰页面底色、接近黑色的文字、一个蓝色行动色，以及独立的成功/警告/危险语义色。深色只保留给窄侧栏或代码/日志区域，不能主导整个屏幕。

禁止项：装饰性渐变、色彩化大卡片、页面级大圆角、状态胶囊泛滥、为图标按钮重复添加文字按钮，以及使用字距收紧来塞进信息。

### 排版与间距

| 用途 | 规格 | 规则 |
| --- | --- | --- |
| 页面标题 | 20px / 28px / 600 | 仅页面 chrome 使用，不得 `clamp()` 到展示级字号 |
| 区块标题 | 16px / 24px / 600 | 与内容间距 12px |
| 正文/表格 | 14px / 20px / 400 | 默认业务信息字号 |
| 元数据/导航 | 13px / 18px / 400 或 500 | 不小于 12px |
| 技术代码 | 12px / 18px / mono | 仅日志、ID、版本等原始字段 |
| 文字字距 | `0` | 不用负字距挤压中文或长 ID |

## 组件契约

| 组件 | 用途 | 规格与状态 |
| --- | --- | --- |
| `AppShell` | 全局导航与内容滚动边界 | 248px 侧栏；64px 内容 chrome；移动端抽屉 |
| `PageHeader` | 页面身份、行动和注意事项 | 标题、可选描述、最多一个主按钮、更多菜单、`AttentionQueue` |
| `Toolbar` | 搜索、筛选、排序、批量操作 | 40px 高；筛选使用图标+文字；低频项进入菜单 |
| `EntityList` | 主从页面的实体浏览 | 336px；搜索、筛选、空/加载/错误状态；键盘上下选择 |
| `EntityDetailHeader` | 实体身份和顶级动作 | 名称、次级元数据、状态、主要动作、溢出菜单 |
| `MetricStrip` | 关键但低噪声的可比指标 | 3--4 列；无卡片阴影；数据缺失显示 `--` |
| `StatusBadge` | 可识别的健康/风险状态 | 文字 + 颜色，成功/警告/错误/中性四种；只用于状态 |
| `ActivityTimeline` | 审计与执行反馈 | 时间、事件、结果、关联对象；错误可展开诊断 |
| `EmptyState` | 无数据、无权限、首次使用 | 一个说明、一个明确行动；不创建嵌套卡片 |
| `ConfirmDialog` | 删除、断开、重置等高风险动作 | 明确对象和后果；危险按钮在最右；可取消 |
| `GuidedFlow` | 多步骤、首次或高风险配置 | 进度、当前目标、一步一个决定、可恢复错误和安全退出 |

### 按钮与图标

- 使用已有 `AppIcon` 或 Lucide 图标。图标按钮必须有 `aria-label` 与悬浮提示。
- `Primary`：蓝底白字，仅用于每个区域的主行动；高度 36px 或 40px。
- `Secondary`：白底边框，用于可逆操作。
- `Tertiary`：无底色，用于低频动作。
- `Destructive`：仅用于删除/断开，放在菜单或确认弹窗中，不能与主要行动并列抢眼。
- 状态切换使用分段控件、勾选框、下拉或开关，不使用看似按钮的文本矩形。
- 详见 [06-引导与可点击性规范.md](./06-引导与可点击性规范.md)：卡片、行、链接、图标按钮和禁用控件必须遵守同一可点击性契约。

## 交互状态

| 状态 | 要求 |
| --- | --- |
| 加载 | 保持布局尺寸的 skeleton；不以整页空白代替 |
| 保存中 | 操作按钮显示进度并禁止重复提交；列表对应行显示短暂状态 |
| 成功 | 在动作邻近处显示简短确认，并更新数值/活动记录 |
| 失败 | 行内解释可恢复原因；提供重试或查看诊断，不只显示 toast |
| 无权限 | 说明权限缺口与可请求的对象，不展示无效主按钮 |
| 离线 | 标签 + 图标 + 最后成功心跳；详情自动将诊断置于首要位置 |

## 无障碍与响应式门槛

- 常规文字与背景对比度至少 4.5:1；大文字至少 3:1；状态文本本身满足对比度。
- 所有可点击目标最低 36 x 36px；图标按钮最低 32 x 32px 且只用于无歧义的熟悉图标。
- 键盘焦点使用 2px `--color-primary` 外框，不能只依赖阴影或颜色变化。
- `prefers-reduced-motion` 下禁用非必要位移和渐显；任何动画小于 150ms 且不改变布局。
- 1280px、1024px、768px、390px 四个视口均需验证文字不重叠、不截断操作标签，实体详情在窄屏可安全返回列表。
