# agent.dofe 首页深度审查与重构

日期：2026-07-25  
范围：未登录首页、邀请入口、公开品牌表达与工作区转化路径。

## 审查结论

旧首页拥有完整的产品素材，但首屏缺少直接登录入口，四项能力在多个区块重复讲述，产品演示与品牌叙事缺乏优先级。用户需要滚动到页面底部才能完成主要任务，属于阻断转化的高优先级问题。

本次参考 `../agents.dofe.ai` 首页的层级方法：首屏明确价值与主行动、紧随真实产品画面、再给能力证据和信任信息。视觉仍沿用本项目已经建立的白、绿、炭黑设计语言，不复制参考项目的色彩或营销装饰。

## 主要问题

| 优先级 | 问题 | 用户影响 | 处理 |
| --- | --- | --- | --- |
| P0 | 登录入口只在长页面底部 | 回访用户无法快速进入工作区 | 顶栏与首屏均提供真实 SSO 链接 |
| P1 | 四项能力在多个区块重复 | 页面冗长，重点不清 | 首屏保留摘要，后续用真实演示展开 |
| P1 | 旧项目名散落于公开界面 | 品牌识别不一致 | 公开显示统一为 `agent.dofe` |
| P1 | 轮播和视频缺少明确状态 | 用户难以判断控件是否生效 | 提供当前序号、活动指示与可访问名称 |
| P2 | 品牌长文一次性全部展示 | 品牌信息压过产品任务 | 首屏只露出核心承诺，六个扩展词按需展开 |
| P2 | 多段视频自动加载 | 首次访问带宽和渲染成本高 | 首屏仅加载当前演示，其余按元数据加载 |

## 信息架构

1. 顶栏：品牌、品牌理念、产品能力、运行模型、登录和语言切换。
2. 首屏：一句产品定位、主要 SSO 行动、产品演示和四项能力摘要。
3. 协作价值：解释从单 Agent 到多人多 Agent 的工作模式。
4. 品牌理念：`Do For E`、愿景、使命和九个 E 词。
5. 产品能力：调度、能力共享、协作和安全的真实界面演示。
6. 运行模型：人类与 Agent 的责任边界。
7. 进入产品：为邀请和普通登录提供完整上下文。

## 品牌表达

- 产品显示名：`agent.dofe`
- 品牌主张：`Do For Employee · Do For Enterprise · Do For Empowerment`
- 愿景：由 `NEXT_PUBLIC_BRAND_VISION` 提供，默认“成为受世界尊敬的中国企业”。
- 使命：由 `NEXT_PUBLIC_BRAND_MISSION` 提供，默认“成就中国智造的全球竞争力”。
- 核心释义：Employee、Enterprise、Empowerment 首屏可见。
- 扩展释义：Execution、Efficiency、Excellence、Ecosystem、Evolution、Escort 由用户主动展开。

内部的 `@agent-space/*` 包名、`AgentSpaceState` 类型、`AGENT_SPACE_*` 环境变量和持久化字段属于兼容协议，不随本次公开品牌升级迁移。

## 交互契约

- 可点击控件必须有目标、状态变化或后续流程；不得保留空 `onClick`。
- 主登录按钮始终指向服务端提供的 SSO 地址，并保留邀请 token。
- 轮播上一项、下一项和圆点均更新当前演示，当前项通过 `aria-current` 暴露。
- 品牌扩展使用原生 `details/summary`，键盘可达并具有开合反馈。
- 页面内导航使用真实锚点；聚焦状态在浅色和深色背景均清晰可见。
- 不可用操作必须设置原生 `disabled` 或 `aria-disabled`，同时移除误导性的悬浮反馈。

## 响应式规则

- 桌面首屏采用文本与产品视频双栏，能力证据保持在首屏下缘。
- 中等宽度将能力摘要改为两列；小屏改为单列，并将视频移动到文案之后。
- 640px 以下隐藏次要导航，但保留品牌、登录和语言切换。
- 固定使用明确字号断点，不随视口连续缩放；所有按钮保持至少 34px 高，核心行动至少 44px 高。

## 验收与度量

- 任务一：新用户在 10 秒内说清产品对象和核心价值。
- 任务二：回访用户无需滚动即可进入 SSO。
- 任务三：用户可以切换产品演示并识别当前项。
- 任务四：键盘用户可访问导航、登录、轮播和品牌展开控件。
- 任务五：360px、768px、1440px 宽度下无溢出、遮挡或文字截断。

当前结论基于代码、现有截图和参考项目对比，尚未经过真实用户访谈。上线后应记录首屏 SSO 点击率、演示切换率、品牌展开率和从首页到工作区的完成时长，并用 5 至 8 名目标用户完成一次任务测试。
