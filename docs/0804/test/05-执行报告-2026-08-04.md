## 5. Skill `fetch failed` 诊断

本次 `fetch failed` 不是 Runtime Docker 的 MCP 外网网关限制导致：

1. CLI-Hub Skill 源同步发生在 AgentSpace Web 服务端进程，不经过 Runtime 容器内的 `curl`，也不经过 Provider 到 MCP egress 的任务网关。
2. 宿主机 Node `fetch` 与宿主机 `curl` 访问同一 MiniMax 文档地址均出现连接重置，故障边界在宿主机到目标站点/其上游网络。
3. 该目录地址是文档 HTML 页面，不是可直接导入的原始 `SKILL.md`。即使网络恢复，也必须先校验响应类型和 Skill 格式。
4. 修复后设置了 8 秒超时、内容校验与安全降级；来源不可达或返回非 Skill 内容时，生成只包含 `minimax --help` 的合法本地 Skill，不执行外部请求。
