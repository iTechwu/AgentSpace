# 02. K22 Runtime 与 AI 员工全量测试用例矩阵

## 1. 执行口径

- 状态只使用：`未执行 / 通过 / 失败 / 阻塞 / 不适用`。
- 标记“两个 Runtime”时，Codex 与 Claude Code 必须分别执行并分别记录，不能用一个结果代替另一个。
- P0 任一失败阻断本专项准出；P1 必须有结果；P2 可进入后续回归但需登记风险。
- `C`=Codex，`A`=Claude Code，`B`=两个 Runtime。
- 矩阵共 98 个唯一场景；按 C/A 展开 Runtime、CLI、MCP、Skill 安装、员工和任务后，最低执行 150 次。若某场景因环境不适用，仍须保留一条“阻塞/不适用”记录及依据。

## 10. 准出统计

专项报告必须同时给出：

- 唯一用例数与按 C/A 展开的实际执行次数。
- P0/P1/P2 的通过、失败、阻塞、不适用数量。
- Codex 与 Claude Code 各自的成功率和主链路耗时。
- 两个 Runtime 的 CLI/MCP/Skill 安装与任务结果对照。
- 未关闭缺陷、阻塞条件、残余资源和 Secret 轮换状态。
