## 一句话决策

将 IM 的读取模型从“消息气泡 + 单个任务时间线 carrier”升级为“按会话排序的稳定执行节点流”：用户消息、助手正文、reasoning、工具调用、工具结果、状态、usage、错误和未知事件均保留稳定身份；每个节点独立增量更新，正文和 reasoning 使用累计文本，工具调用按 `refId` 关联输入/输出，界面只在用户主动操作时展开或收起。

## 范围与边界

- **完整展现**指完整保留并展示 Harness/daemon 已通过协议报告的可见事件，不意味着展示未通过协议输出的隐藏 chain-of-thought。
- SSE 继续只承担低延迟失效通知；完整内容从持久化读取接口获取，断线、丢事件和刷新都能恢复。
- 首期不改变任务队列、provider 选择、权限模型或 Markdown 解析器；先建立事件保真和节点投影，再做视觉细节。
- 不将每个 token 变成独立 React 行，不为每次 delta 创建聊天气泡；采用累计快照 + `requestAnimationFrame` 合并提交。
