5. 新增集中 SLO 快照账本、周期 flush、跨实例加权汇总、deadlock/P2034 识别、burn-rate/pager 告警与发布回滚适配器契约；相关定向测试通过。

7. 新增剩余 Prisma 写路径 inventory，明确事务、幂等、事件与 legacy 退出条件。

9. 修复 node.ready Prisma 切流审查问题：run→node 事务锁顺序、终态复检、审批节点 legacy 回退、queue unavailable 退避、queue/link affected rows、生命周期事件幂等、outbox 单次 attempt 与 Serializable 冲突重试均已落地并通过定向测试。
10. 修正连接池压测采集时机和 `pg_sleep` void 结果的 Prisma P2010 反序列化问题；观察发生在负载期间，CLI 分离 connection/statement timeout，并已完成 Web/worker/daemon 基线、过载与 in-flight shutdown 隔离库验收。
11. 将 run.ready/resumed 改为原子 outbox fan-out：父事件和所有 ready node 子事件同事务提交，子事件使用 parent+node digest 幂等 ID；真实 PostgreSQL 已验证双 worker 竞争、末段 publish 失败整体回滚、同 run 并发与反向行锁 40P01 自动重试。
12. 新增 `prisma-shadow-readiness` 准入门禁，从集中 audit ledger 读取完整 30 天窗口，校验覆盖起止、最大间隙、minimum samples、mismatch/fallback/error、deadlock/P2034 和 rollback recommendation；当前 `workflow-dispatcher` 实测返回 `ready=false`（`no_snapshots`、`insufficient_samples`），不允许开启 write flag。
13. 新增 materialization Prisma Serializable API，definition/trigger 行锁、trigger-key 幂等、节点物化、根节点 ready、run 事件、run.ready outbox 和 trigger advance 同事务提交；workflow worker 的 auto scheduler 已受 fail-closed write flag 接线到该路径，真库验证末段 lease 冲突整体回滚。
14. 新增 coordinator Prisma 原子原语：先按 run→node 锁定，再以 CAS 将 downstream node 从 pending 转 ready 并写入 `workflow.node.ready` outbox；真库验证 outbox 主键冲突时节点状态与 input 整体回滚。
