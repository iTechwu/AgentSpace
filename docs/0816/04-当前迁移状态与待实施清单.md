1. **P1：完成连接池容量运行证据。** 先准备隔离测试库，再分别执行：
   `pnpm --filter @dofe-agent/db run prisma:pool:loadtest -- --database-url <isolated-test-url> --role web --concurrency 20 --hold-ms 250 --timeout-ms 5000 --json`（worker/daemon 同理）。保存三份 JSON，并用 `prisma:pool:evidence` 在查询保持期间采集 active/waiting；验收必须同时有 completed、timedOut、P95、池上限、waiting 和 graceful shutdown。普通 dev/生产库会被 CLI 拒绝。
2. **P1：配置真实 webhook 并完成恢复演练。** 当前代码和 env 入口已就绪，但仓库没有真实 webhook 凭据；部署时必须先用 warning/error 告警，再清除条件验证 recovery payload 未丢失且只消费一次。
