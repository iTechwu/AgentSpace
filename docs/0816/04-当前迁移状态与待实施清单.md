2. **P1：扩展 invariant gate。** 比较 CHECK 表达式、partial index predicate、enum label、view definition 和 function body hash，而不只检查对象名称。
3. **P1：建立连接池容量证据。** 分别记录 Web、worker、daemon 的 active/waiting/timeout、P95 和 graceful shutdown。
4. **P1：聚合 cutover SLO。** 按域统计 mismatch/fallback/deadlock/P2034，输出带 last-known-good flag 版本的回滚建议。
5. **P2：建立剩余写路径 inventory。** 每条路径记录调用方、事务边界、幂等键、affected rows、事件副作用和退出 legacy 的验收条件。
