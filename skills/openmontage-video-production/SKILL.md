# OpenMontage 视频生成

## 适用场景

当用户要求生成、改编、配字幕、配音、审批、跟踪或交付视频时，使用本 Skill。它通过 AgentSpace 已批准的 OpenMontage MCP 工具运行异步视频 Job。

## 前置约束

- 只使用 AgentSpace 中名为 `official-openmontage` 的已批准 MCP 连接，不在提示词中写入服务地址、令牌或本机路径。
- 首次调用 `openmontage_capabilities`，确认 OpenMontage 服务、可用工作流和视频模型状态。
- 在提交 Job 前确认创意简报：受众、时长、画幅、风格、语言、素材来源、字幕/配音需求和交付格式。
- 生成视频需要明确的用户批准。没有批准时只能完成能力探测、提示词整理或草稿，不得声称已渲染或已发布。

## 标准流程

1. 调用 `openmontage_capabilities`，选择能力目录中明确支持的工作流和模型。
2. 将简报整理为包含 Subject、Motion、Scene、Spatial、Camera 五个方面的镜头提示词。字幕、标题、Logo 和其他叠加内容作为独立 overlay 计划，不混入视觉提示词。
3. 调用 `submit_video_job` 提交异步 Job，保存返回的 `jobId` 和 `lastSequence`。
4. 若 Job 暂停在审批阶段，向用户展示待审批阶段和成本/时长摘要；只在用户批准后调用 `approve_video_stage`。
5. 使用 `get_video_job` 和 `list_video_job_events` 轮询状态，按 `lastSequence` 去重，遇到失败或取消状态停止轮询。
6. 完成后调用 `list_video_artifacts` 获取可交付产物。只有拿到成功状态和产物 URL 后，才能向用户报告视频已生成。
7. 用户取消时调用 `cancel_video_job`，并记录最终状态。

## 提示词规范

每个镜头至少说明：

- **Subject**：主体、外观、身份和关键道具。
- **Motion**：主体动作、速度、方向和连续变化。
- **Scene**：地点、时间、天气、材质和背景事件。
- **Spatial**：主体之间的相对位置、景别和前中后景关系。
- **Camera**：机位、镜头、焦段、运动方式、构图和转场。

避免把多个独立创意塞入单个镜头；需要多个镜头时拆分为可验证的阶段，并保持角色、色彩和时间线的一致性。

## 质量与边界

- 在能力目录不支持某个模型或工作流时，说明原因并请求替代方案，不绕过服务端校验。
- 不把“已提交”描述为“已完成”，不把预览描述为最终交付。
- 失败时保留 `jobId`、失败阶段和最后事件序号，便于重试或人工排查。
- 对涉及真人、品牌、版权素材、声音克隆或敏感内容的请求，先确认授权和使用范围。
